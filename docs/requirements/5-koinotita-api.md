# Κοινότητα & API

**Υπεύθυνη:** Κριτσίμη Δήμητρα

| Κωδικός | Λειτουργική απαίτηση | Χρήστης | Προτεραιότητα |
|---|---|---|---|
| ΚΟ-01 | Ο χρήστης μπορεί να δει την κατάταξη παικτών (leaderboard) ενός σεναρίου με βάση τους πόντους και τον χρόνο | Όλοι | Υψηλή |
| ΚΟ-02 | Ο χρήστης μπορεί να δει τη γενική κατάταξη παικτών | Όλοι | Μεσαία |
| ΚΟ-03 | Ο χρήστης μπορεί να δει την κατάταξη της συνεδρίας ή της τάξης του | Όλοι | Υψηλή |
| ΚΟ-04 | Ο χρήστης μπορεί να δει τη μέση βαθμολογία και τον αριθμό αξιολογήσεων κάθε σεναρίου | Όλοι | Μεσαία |
| ΚΟ-05 | Το σύστημα εξαιρεί τον δημιουργό ενός σεναρίου από την κατάταξη των δικών του σεναρίων | Σύστημα | Υψηλή |
| ΚΟ-06 | Ο παίκτης μπορεί να βαθμολογήσει ένα σενάριο με 1–5 αστέρια αφού ολοκληρώσει την υπόθεση | Παίκτης | Μεσαία |
| ΚΟ-07 | Ο παίκτης μπορεί να αφήσει σχόλιο σε ένα σενάριο που ολοκλήρωσε | Παίκτης | Μεσαία |
| ΚΟ-08 | Ο παίκτης μπορεί να αναφέρει πρόβλημα σε ένα σενάριο (π.χ. λάθος απάντηση)| Παίκτης | Μεσαία |
| ΚΟ-09 | Ο δημιουργός μπορεί να δει τα σχόλια των παικτών για τα σενάριά του | Δημιουργός | Μεσαία |
| ΚΟ-10 | Ο δημιουργός μπορεί να δει στατιστικά για κάθε σενάριό του (πόσοι έπαιξαν, πόσοι το έλυσαν, μέσο χρόνο και σε ποιον γρίφο κόλλησαν) | Δημιουργός | Υψηλή |
| ΚΟ-11 | Ο δημιουργός μπορεί να φιλτράρει τα στατιστικά ενός σεναρίου ανά συνεδρία ή τάξη | Δημιουργός | Χαμηλή |
| ΚΟ-12 | Ο διαχειριστής μπορεί να δει στον πίνακα ελέγχου συγκεντρωτικά στοιχεία και εκκρεμότητες του συστήματος | Admin | Μεσαία |
| ΚΟ-13 | Ο διαχειριστής μπορεί να ελέγξει υποβληθέντα σενάρια και να τα εγκρίνει ή να τα απορρίψει για δημόσια δημοσίευση | Admin | Υψηλή |
| ΚΟ-14 | Ο διαχειριστής μπορεί να δει τις αναφορές και να τις επισημάνει ως επιλυμένες | Admin | Μεσαία |
| ΚΟ-15 | Ο διαχειριστής μπορεί να επιστρέψει ένα σενάριο στον δημιουργό με σχόλιο διόρθωσης | Admin |Υψηλή |
| ΚΟ-16 | Μια εξωτερική εφαρμογή μπορεί να λάβει τη λίστα των δημόσιων σεναρίων μέσω του API μας | Εξωτερική εφαρμογή | Μεσαία |
| ΚΟ-17 | Μια εξωτερική εφαρμογή μπορεί να λάβει το leaderboard ενός δημόσιου σεναρίου μέσω του API μας | Εξωτερική εφαρμογή | Μεσαία |
| ΚΟ-18 | Το API επιστρέφει τα δεδομένα σε μορφή JSON  | Εξωτερική εφαρμογή | Μεσαία |
