# Κοινότητα & API

**Υπεύθυνη:** [Κριτσίμη Δήμητρα]

| Κωδικός | Λειτουργική απαίτηση | Χρήστης | Προτεραιότητα |
|---|---|---|---|
| ΚΟ-01 | Ο χρήστης μπορεί να δει την κατάταξη παικτών (leaderboard) ενός σεναρίου με βάση τους πόντους και τον χρόνο | Όλοι | Υψηλή |
| ΚΟ-02 | Ο χρήστης μπορεί να δει τη γενική κατάταξη παικτών και την κατάταξη της συνεδρίας ή της τάξης του | Όλοι | Μεσαία |
| ΚΟ-03 | Το σύστημα εξαιρεί τον δημιουργό ενός σεναρίου από την κατάταξη των δικών του σεναρίων | Σύστημα | Υψηλή |
| ΚΟ-04 | Ο παίκτης μπορεί να βαθμολογήσει ένα σενάριο με 1–5 αστέρια αφού ολοκληρώσει την υπόθεση | Παίκτης | Μεσαία |
| ΚΟ-05 | Ο δημιουργός μπορεί να δει στατιστικά για κάθε σενάριό του (πόσοι έπαιξαν, πόσοι το έλυσαν, μέσο χρόνο και σε ποιον γρίφο κόλλησαν) | Δημιουργός | Υψηλή |
| ΚΟ-06 | Ο δημιουργός μπορεί να φιλτράρει τα στατιστικά ενός σεναρίου ανά συνεδρία ή τάξη | Δημιουργός | Χαμηλή |
| ΚΟ-07 | Ο διαχειριστής μπορεί να δει στον πίνακα ελέγχου συγκεντρωτικά στοιχεία και εκκρεμότητες του συστήματος | Admin | Μεσαία |
| ΚΟ-08 | Ο διαχειριστής μπορεί να ελέγξει υποβληθέντα σενάρια και να τα εγκρίνει ή να τα απορρίψει για δημόσια δημοσίευση | Admin | Υψηλή |
| ΚΟ-09 | Μια εξωτερική εφαρμογή μπορεί να λάβει τη λίστα των δημόσιων σεναρίων μέσω του API μας | Εξωτερική εφαρμογή | Μεσαία |
| ΚΟ-10 | Μια εξωτερική εφαρμογή μπορεί να λάβει το leaderboard ενός δημόσιου σεναρίου μέσω του API μας | Εξωτερική εφαρμογή | Μεσαία |
