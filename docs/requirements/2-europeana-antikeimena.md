# Europeana & αντικείμενα

**Υπεύθυνη:** Κουτουβού Κατερίνα

| Κωδικός | Λειτουργική απαίτηση | Χρήστης | Προτεραιότητα |
|---|---|---|---|
| ΑΝ-01 | Ο δημιουργός μπορεί να αναζητήσει πολιτιστικά αντικείμενα από την Europeana χρησιμοποιώντας λέξεις-κλειδιά | Δημιουργός | Υψηλή |
| ΑΝ-02 | Ο δημιουργός μπορεί να φιλτράρει τα αποτελέσματα αναζήτησης βάσει χρονικής περιόδου, γεωγραφικής τοποθεσίας και τύπου αντικειμένου | Δημιουργός | Υψηλή |
| ΑΝ-03 | Το σύστημα ανακτά αναλυτικές πληροφορίες πολιτιστικών αντικειμένων μέσω του Europeana Record API | Σύστημα | Υψηλή |
| ΑΝ-04 | Ο δημιουργός μπορεί να δει τα διαθέσιμα μεταδεδομένα ενός αντικειμένου, όπως τίτλο, δημιουργό, χρονολογία, περιγραφή και εικόνα | Δημιουργός | Υψηλή |
| ΑΝ-05 | Το σύστημα ελέγχει εάν κάθε αντικείμενο διαθέτει χρονολογία, δημιουργό και εικόνα | Σύστημα | Υψηλή |
| ΑΝ-06 | Ο δημιουργός μπορεί να επιλέξει την εμφάνιση μόνο αντικειμένων που διαθέτουν τα απαιτούμενα μεταδεδομένα | Δημιουργός | Υψηλή |
| ΑΝ-07 | Ο δημιουργός μπορεί να επιλέξει πολιτιστικά αντικείμενα για χρήση στο σενάριό του | Δημιουργός | Υψηλή |
| ΑΝ-08 | Το σύστημα αποθηκεύει τοπικά τα επιλεγμένα αντικείμενα και τα μεταδεδομένα τους (caching) | Σύστημα | Υψηλή |
| ΑΝ-09 | Το σύστημα αναγνωρίζει ήδη αποθηκευμένα αντικείμενα μέσω του μοναδικού αναγνωριστικού Europeana και αποτρέπει τη διπλότυπη αποθήκευσή τους | Σύστημα | Υψηλή |
| ΑΝ-10 | Το σύστημα καταγράφει τις ενέργειες αποθήκευσης, ενημέρωσης και αποτυχίας της cache | Σύστημα | Μεσαία |
| ΑΝ-11 | Ο χρήστης μπορεί να εξετάσει σε μεγέθυνση την εικόνα ενός εκθέματος μέσω IIIF, όπου υποστηρίζεται | Δημιουργός / Παίκτης | Υψηλή |
| ΑΝ-12 | Το σύστημα διαθέτει τα αποθηκευμένα αντικείμενα και τα μεταδεδομένα τους στον επεξεργαστή σεναρίων και στο υποσύστημα εκτέλεσης παιχνιδιού | Σύστημα | Υψηλή |
| ΑΝ-13 | Το σύστημα διαχειρίζεται αποτυχημένα αιτήματα, μη διαθέσιμα αντικείμενα και περιπτώσεις αδυναμίας επικοινωνίας με την Europeana | Σύστημα | Υψηλή |
| ΑΝ-14 | Το σύστημα διατηρεί την πηγή προέλευσης και τις διαθέσιμες πληροφορίες δικαιωμάτων χρήσης κάθε πολιτιστικού αντικειμένου | Σύστημα | Υψηλή |
| ΑΝ-15 | Ο δημιουργός μπορεί να συμπληρώσει ή να διορθώσει μεταδεδομένα που λείπουν ή είναι λάθος (π.χ. χρονολογία) | Δημιουργός | Υψηλή |
| ΑΝ-16 | Ο δημιουργός μπορεί να αποθηκεύσει αντικείμενα στη συλλογή του | Δημιουργός | Υψηλή |
| ΑΝ-17 | Ο δημιουργός μπορεί να δει τη συλλογή του και να τη φιλτράρει ανά σενάριο | Δημιουργός | Μεσαία |
| ΑΝ-18 | Ο διαχειριστής μπορεί να εγκρίνει ή να απορρίψει τις διορθώσεις μεταδεδομένων | Admin | Μεσαία |
| ΑΝ-19 | Ο παίκτης μπορεί να δει στο τέλος του παιχνιδιού τα πραγματικά στοιχεία των εκθεμάτων και σύνδεσμο προς την Europeana | Παίκτης | Μεσαία |
