# Editor Σεναρίων

**Υπεύθυνη:** Παπαστεργίου Αργυρώ

| Κωδικός | Λειτουργική απαίτηση | Χρήστης | Προτεραιότητα |
|---|---|---|---|
| ΕΔ-01 | Ο δημιουργός μπορεί να ξεκινήσει νέο σενάριο επιλέγοντας τύπο (φόνος ή escape room) | Δημιουργός | Υψηλή |
| ΕΔ-02 | Ο δημιουργός μπορεί να ορίσει τίτλο, εποχή, τόπο, ηλικίες, δυσκολία, εκτιμώμενη διάρκεια, σύντομη περιγραφή και εξώφυλλο | Δημιουργός | Υψηλή |
| ΕΔ-03 | Ο δημιουργός μπορεί να γράψει την ιστορία (εισαγωγή) και τη λύση του σεναρίου | Δημιουργός | Υψηλή |
| ΕΔ-04 | Ο δημιουργός μπορεί να προσθέσει 3–6 αντικείμενα ως στοιχεία και να γράψει για καθένα γρίφο, σωστή απάντηση και αποδεκτές παραλλαγές | Δημιουργός | Υψηλή |
| ΕΔ-05 | Ο δημιουργός μπορεί να γράψει έως 3 hints για κάθε στοιχείο | Δημιουργός | Μεσαία |
| ΕΔ-06 | Ο δημιουργός μπορεί, μέσα από τον οδηγό, να χρησιμοποιήσει τη διόρθωση στοιχείων αντικειμένου (βλ. ΑΝ) | Δημιουργός | Μεσαία |
| ΕΔ-07 | (Φόνος) Ο δημιουργός μπορεί να ορίσει υπόπτους με άλλοθι, να σημειώσει τον δράστη και ποια στοιχεία αποδεικνύουν την ενοχή | Δημιουργός | Υψηλή |
| ΕΔ-08 | (Escape room) Ο δημιουργός μπορεί να ορίσει κλειδαριές με κωδικό και το στοιχείο που τον κρύβει | Δημιουργός | Υψηλή |
| ΕΔ-09 | Ο δημιουργός μπορεί να αποθηκεύσει ένα σενάριο ως πρόχειρο και να το συνεχίσει ή να το δημοσιεύσει αργότερα | Δημιουργός | Υψηλή |
| ΕΔ-10 | Ο δημιουργός μπορεί να επιλέξει αν το σενάριο θα είναι δημόσιο (μετά από έγκριση admin) ή μόνο για τις ομάδες μου | Δημιουργός | Υψηλή |
| ΕΔ-11 | Ο δημιουργός μπορεί να δει τα σενάριά του με την κατάστασή τους (πρόχειρο, σε έλεγχο, δημοσιευμένο, μόνο για τις ομάδες μου) | Δημιουργός | Μεσαία |
| ΕΔ-12 | Το σύστημα δεν επιτρέπει δημοσίευση αν το σενάριο είναι ελλιπές (πχ λιγότερα από 3 στοιχεία ή χωρίς δράστη) και λέει τι λείπει | Σύστημα | Υψηλή |
| ΕΔ-13 | Ο δημιουργός μπορεί να διαγράψει ένα δικό του πρόχειρο σενάριο | Δημιουργός | Μεσαία |
| ΕΔ-14 | Μόνο ο δημιουργός ενός σεναρίου μπορεί να το επεξεργαστεί ή να το διαγράψει | Σύστημα | Υψηλή |
| ΕΔ-15 | Αν ο admin επιστρέψει ένα σενάριο, ο δημιουργός βλέπει το σχόλιο, το διορθώνει και το υποβάλλει ξανά | Δημιουργός | Μεσαία |
| ΕΔ-16 | Ο δημιουργός μπορεί να δοκιμάσει το σενάριο όπως θα το δει ο παίκτης, χωρίς να μετρήσει στα στατιστικά | Δημιουργός | Χαμηλή |
| ΕΔ-17 | Ο δημιουργός μπορεί να αλλάξει τη σειρά των στοιχείων με σύρσιμο | Δημιουργός | Χαμηλή |
| ΕΔ-18 | Ο δημιουργός μπορεί να αποσύρει ένα σενάριο που είναι σε έλεγχο | Δημιουργός | Χαμηλή |
| ΕΔ-19 | Ο δημιουργός μπορεί να υποβάλει αργότερα για δημόσιο ένα σενάριο που είχε ορίσει «μόνο για τις ομάδες του» | Δημιουργός | Χαμηλή |
| ΕΔ-20 | Ο δημιουργός μπορεί να παίζει με την ομάδα του ένα σενάριο που περιμένει έγκριση από τον admin | Δημιουργός | Μεσαία |
| ΕΔ-21 | Ο δημιουργός μπορεί να φτιάξει αντίγραφο ενός σεναρίου του και να το αλλάξει | Δημιουργός | Χαμηλή |
| ΕΔ-22 | Ο δημιουργός μπορεί να ξεκινήσει συνεδρία ή να ανοίξει τα στατιστικά ενός σεναρίου από τη λίστα «Τα σενάριά μου» | Δημιουργός | Μεσαία | 
| ΕΔ-23 | Ο δημιουργός μπορεί να ορίσει όριο χρόνου και (φόνος) αριθμό προσπαθειών κατηγορίας | Δημιουργός | Υψηλή |
| ΕΔ-24 | (Escape room) Ο δημιουργός μπορεί να ορίσει γρίφο χρονολογικής σειράς εκθεμάτων | Δημιουργός | Μεσαία |
