# Λειτουργικές απαιτήσεις

Εδώ κάθε μέλος ανεβάζει τις λειτουργικές απαιτήσεις του υποσυστήματός του,
σε ξεχωριστό αρχείο. Στο τέλος ενώνονται όλες σε μία σελίδα στο Wiki
για την ενδιάμεση παράδοση (13/12).

## Πρότυπο (αντιγράψτε το στο αρχείο σας)

    # [Όνομα υποσυστήματος]

    **Υπεύθυνη:** [Όνομα]

    | Κωδικός | Λειτουργική απαίτηση | Χρήστης | Προτεραιότητα |
    |---|---|---|---|
    | ΧΡ-01 | Ο επισκέπτης μπορεί να κάνει εγγραφή με email και κωδικό | Επισκέπτης | Υψηλή |

## Κανόνες

- Κάθε απαίτηση ξεκινάει με «Ο [χρήστης] μπορεί να…» ή «Το σύστημα…».
- Μία ενέργεια ανά γραμμή.
- Προτεραιότητα: Υψηλή / Μεσαία / Χαμηλή.
- Ανεβάζουμε με νέα branch και pull request, όχι κατευθείαν στο `main`.
