# Game engine

**Υπεύθυνη:** Ελένη Τσότσου

| Κωδικός | Λειτουργική απαίτηση | Χρήστης | Προτεραιότητα |
|---|---|---|---|
| ΠΑ-01 | Ο παίκτης μπορεί να απαντήσει σε έναν γρίφο και να μάθει αμέσως αν είναι σωστός | Παίκτης | Υψηλή |
| ΠΑ-02 | Ο παίκτης μπορεί να κατηγορήσει έναν ύποπτο και να δει αν έλυσε το μυστήριο (φόνος) | Παίκτης | Υψηλή |
| ΠΑ-03 | Ο παίκτης βλέπει χρονόμετρο και, αν τελειώσει ο χρόνος, το παιχνίδι λήγει | Παίκτης | Υψηλή |
| ΠΑ-04 | Ο παίκτης μπορεί να ζητήσει hint, χάνοντας πόντους | Παίκτης | Μεσαία |
| ΠΑ-05 | Ο παίκτης μπορεί να σταματήσει ένα παιχνίδι που παίζει εκτός συνεδρίας και να το συνεχίσει αργότερα από το ίδιο σημείο | Παίκτης | Χαμηλή |
| ΠΑ-06 | Ο χρήστης μπορεί να δει την εισαγωγή ενός σεναρίου (ιστορία, δυσκολία, διάρκεια, εποχή, ηλικίες) πριν ξεκινήσει | Παίκτης | Υψηλή |
| ΠΑ-07 | Ο επισκέπτης που μπήκε με κωδικό συνεδρίας βλέπει σύντομη εισαγωγή του σεναρίου πριν ξεκινήσει | Επισκέπτης | Μεσαία |
| ΠΑ-08 | Ο παίκτης μπορεί να εξετάσει κάθε έκθεμα σε μεγέθυνση μαζί με τα στοιχεία του | Παίκτης | Υψηλή |
| ΠΑ-09 | Το σύστημα ξεκλειδώνει το επόμενο στοιχείο όταν ο παίκτης λύσει σωστά τον γρίφο | Σύστημα | Υψηλή |
| ΠΑ-10 | Ο παίκτης μπορεί να δει τους υπόπτους και τις καταθέσεις τους (φόνος) | Παίκτης | Υψηλή |
| ΠΑ-11 | Ο παίκτης μπορεί να επιλέξει τα στοιχεία που αποδεικνύουν την ενοχή του υπόπτου πριν τον κατηγορήσει (φόνος) | Παίκτης | Μεσαία |
| ΠΑ-12 | Ο παίκτης μπορεί να βάλει κωδικό (αριθμό ή λέξη) σε λουκέτο, και η πόρτα ανοίγει όταν ανοίξουν όλα τα λουκέτα (escape room) | Παίκτης | Υψηλή |
| ΠΑ-13 | Ο παίκτης μπορεί να τοποθετήσει εκθέματα σε χρονολογική σειρά ως γρίφο (escape room) | Παίκτης | Μεσαία |
| ΠΑ-14 | Όταν ο παίκτης κατηγορήσει λάθος ύποπτο, βλέπει το άλλοθί του, τους πόντους που έχασε και τις προσπάθειες που απομένουν, και μπορεί να ξαναπροσπαθήσει (φόνος) | Παίκτης | Μεσαία |
| ΠΑ-15 | Το σύστημα υπολογίζει τους πόντους με βάση τον χρόνο, τα hints και τα λάθη | Σύστημα | Υψηλή |
| ΠΑ-16 | Ο παίκτης βλέπει οθόνη αποτελέσματος με τον χρόνο και τους πόντους του όταν λύσει το μυστήριο | Παίκτης | Υψηλή |
| ΠΑ-17 | Ο παίκτης βλέπει ότι η υπόθεση έμεινε ανεξιχνίαστη όταν λήξει ο χρόνος και μπορεί να δει τη λύση | Παίκτης | Μεσαία |
| ΠΑ-18 | Ο παίκτης μπορεί να ξαναπαίξει ένα σενάριο | Παίκτης | Χαμηλή |
| ΠΑ-19 | Το σύστημα αποθηκεύει το αποτέλεσμα του παιχνιδιού για την κατάταξη και το προφίλ του παίκτη | Σύστημα | Υψηλή |
| ΠΑ-20 | Το σύστημα ενημερώνει την πρόοδο του παίκτη στη συνεδρία, ώστε να τη βλέπει ο δημιουργός | Σύστημα | Μεσαία |
| ΠΑ-21 | Ο παίκτης έχει σημειωματάριο όπου μπορεί να γράφει σημειώσεις κατά τη διάρκεια του παιχνιδιού | Παίκτης | Χαμηλή |
| ΠΑ-22 | Όταν ο παίκτης δώσει λάθος κωδικό σε λουκέτο, βλέπει μήνυμα λάθους και χάνει πόντους, ενώ το λάθος καταγράφεται στο αποτέλεσμα (escape room) | Παίκτης | Μεσαία |
